### Rakada — Order & COD Financial Management

**Client project · Private source code**

A SaaS platform that helps merchants follow orders, cash-on-delivery collections, returns, and shipping company payments.

Key features include order synchronization, subscription management, returns tracking, and comparing expected collections with payments received from shipping companies.

**My work:** backend architecture, merchant data isolation, Salla OAuth and webhooks, background order sync, subscriptions, financial reconciliation, and deployment.

**Stack:** Node.js, Express.js, PostgreSQL, Sequelize, Redis, BullMQ, Docker, Nginx.

[Visit the product](https://rkada.com/)
